# Poker Tracker (SwiftUI)

Простой учебный iOS-проект:
- авторизация (логин + регистрация),
- добавление игры в формате `ник - закуп - выкуп`,
- экран общей статистики по всем играм.

## Что реализовано

- Локальная авторизация через `UserDefaults`.
- Сохранение всех игр в `UserDefaults`.
- Автоматический расчет:
  - количество игр,
  - суммарный результат,
  - средний результат,
  - максимальный выигрыш,
  - максимальный проигрыш.
- Список всех добавленных игр с датой и результатом.

## Структура файлов

- `PokerApp.swift` - точка входа приложения.
- `RootView.swift` - переключение между логином и основным интерфейсом.
- `LoginView.swift` - экран входа/регистрации.
- `MainTabView.swift` - табы приложения.
- `AddGameView.swift` - форма добавления игры.
- `StatisticsView.swift` - статистика и список игр.
- `Models.swift` - модели данных.
- `AuthViewModel.swift` - логика авторизации.
- `GameStore.swift` - хранение игр и расчет статистики.

## Как запустить

1. Открой Xcode.
2. Создай новый проект: **iOS -> App** (SwiftUI).
3. Замени сгенерированные файлы на файлы из этой папки.
4. Запусти на симуляторе.
